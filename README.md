# ParkSmart - Sistema Inteligente de Gestión de Parqueaderos

Proyecto académico desarrollado para la asignatura de **Ingeniería de Software - UNIMINUTO 2026**.

## Descripción del Proyecto
ParkSmart es una solución digital diseñada para optimizar la administración y gestión de espacios de estacionamiento en entornos de alta afluencia. La plataforma permite la visualización en tiempo real, reserva de espacios, control de accesos y gestión administrativa, mejorando la eficiencia operativa mediante una interfaz intuitiva y responsive.

## Tecnologías Utilizadas
Este proyecto está desarrollado bajo el paradigma **SPA (Single Page Application)** utilizando tecnologías web estándar:
- **HTML5:** Estructura semántica del sistema.
- **CSS3:** Diseño responsivo, variables CSS y componentes de interfaz.
- **JavaScript (ES6+):** Lógica de negocio, manejo de estado global y manipulación del DOM (Vanilla JS).
- **Git/GitHub:** Control de versiones y despliegue continuo.
